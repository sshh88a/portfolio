# 项目规则：个人作品集网站（AI 辅助开发约定）

本规则由实验过程中的有效做法沉淀而来，AI 在本项目中工作时必须遵守。

## 项目概况

- 纯静态个人作品集网站（HTML/CSS/JS），无框架、无构建工具、无第三方 UI 库
- 面向老师、同学和企业招聘人员
- 双击 `index.html` 或本地服务器即可运行，必须完全离线可用

## 文件与架构约定

| 文件 | 职责 | 约束 |
|---|---|---|
| `index.html` | 页面骨架与区块容器 | 项目区只保留渲染占位容器，不写死项目内容 |
| `styles.css` | 全部样式 | 设计变量集中在 `:root`，改风格先改变量 |
| `data.js` | 个人信息 + 项目数据（唯一事实来源） | 内容修改只改这里，不往 HTML 里塞内容 |
| `script.js` | 渲染与交互 | 版式按数组顺序自动轮换，不针对单个项目写特例 |
| `image/` | 项目截图 | 同名覆盖即可换图，无需改代码 |

- 新增项目 = 在 `data.js` 的项目数组加一条对象（字段：名称、简介、技术栈、开始/完成时间、类别、tags、图片路径、featured）
- 真实资料来源是 `profile_demo.md`，内容替换以它为准，禁止编造个人信息和数据

## 视觉规范

- 风格：彩色渐变活力风（紫 `#7c5cff` → 粉 → 橙），弥散渐变光晕背景
- 禁止：卡片式等宽网格、技能进度条、工作经历时间轴等"传统简历"元素
- 动画克制：仅滚动淡入、hover 微交互，不做视差和复杂转场
- 中文标题使用系统中文字体栈，不依赖需联网的字体服务

## 修改纪律（迭代边界）

1. 用户指令含"只改 X"时，严禁顺手重构或优化其他区域
2. 每次改动后升级资源版本号（`?v=N`），避免浏览器缓存旧文件
3. 占位内容必须标注 TODO，且集中在 `data.js`
4. 报告完成前必须实际验证：`node --check` 语法检查、HTTP 确认文件可达、必要时浏览器截图
5. 验证工具结果与肉眼观察冲突时，优先换用确定性手段复核，不盲目相信截图

## 验收标准

- 各区块显示完整，项目卡片信息齐全（名称/简介/技术栈/起止时间/类别 tag/图片）
- 桌面端与 375px 移动端无明显布局问题、无水平溢出、无死链（`href="#"` 仅允许明确标注 TODO 的项）
- 控制台无 JS 报错
