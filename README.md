# 小恒 · 个人作品集网站

一个纯静态的个人作品集网站，面向老师、同学和企业招聘人员。无框架、无构建工具、无第三方 UI 库，双击 `index.html` 或任意本地服务器即可运行，完全离线可用。

## 功能特性

- **项目作品展示**：4 个项目卡片，含名称、简介、技术栈、起止时间、类别标签与截图；`featured` 项目自动使用通栏大图版式，其余为图左文右版式（偶数项图在右）
- **深浅色主题切换**：导航栏右上角悬浮主题按钮，一键切换浅色/深色；选择保存在 `localStorage`，首次访问跟随系统偏好；内联脚本在首屏提前应用主题，避免深色模式刷新闪白
- **响应式布局**：桌面端与移动端（375px）自适应，移动端提供汉堡全屏菜单
- **克制的动效**：滚动淡入（IntersectionObserver）、hover 微交互、导航当前章节高亮，无动画偏好（`prefers-reduced-motion`）时自动关闭
- **视觉风格**：彩色渐变活力风（紫 `#7c5cff` → 粉 → 橙），弥散渐变光晕背景，系统中文字体栈

## 目录结构

```
lab04/
├── index.html      # 页面骨架与区块容器（项目区只保留渲染占位容器）
├── styles.css      # 全部样式，设计变量集中在 :root，深色主题经 [data-theme="dark"] 覆盖
├── data.js         # 个人信息 + 项目数据（唯一事实来源）
├── script.js       # 渲染与交互（项目/技能/联系链接渲染、主题切换、导航、滚动动画）
├── image/          # 项目截图，与项目同名，替换文件即可换图
├── profile_demo.md # 真实资料来源
└── README.md
```

## 快速开始

直接双击 `index.html` 即可在浏览器中打开；或使用本地服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 内容维护

- **修改个人信息 / 项目内容**：只改 `data.js`，不要往 HTML 里塞内容
- **新增项目**：向 `data.js` 的 `PROJECTS` 数组追加一条对象，字段包括：
  `title`（名称）、`intro`（简介）、`tech`（技术栈数组）、`start` / `date`（起止时间）、`category`（类别）、`tags`、`image`（图片路径）、`featured`（是否通栏大图）
- **更换截图**：把新图放入 `image/` 同名覆盖即可，无需改代码
- **调整风格**：优先修改 `styles.css` 中 `:root` 的设计变量
- **缓存刷新**：改动资源后升级 `index.html` 中引用的版本号（`?v=N`）

## 技术说明

| 文件 | 职责 |
|---|---|
| `index.html` | 语义化区块结构；`<head>` 内联脚本提前应用主题 |
| `styles.css` | 设计变量（浅色 `:root` / 深色 `[data-theme="dark"]`）、弥散渐变背景、响应式断点（1200 / 900 / 720px） |
| `script.js` | 依据 `data.js` 渲染项目、技能、联系链接；主题切换与 `localStorage` 记忆；导航滚动态、章节高亮、移动端菜单、滚动淡入动画 |

## 浏览器验证清单

- 各区块显示完整，项目卡片信息齐全（名称/简介/技术栈/起止时间/类别标签/图片）
- 主题切换即时生效，刷新后保持上次选择
- 桌面端与 375px 移动端无水平溢出、无死链
- 控制台无 JS 报错
